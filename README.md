# Life Admin Copilot — Personal Operations Studio

Turn administrative clutter into calm, actionable clarity.

Live Demo: [https://neurelith.github.io/life-admin-copilot/](https://neurelith.github.io/life-admin-copilot/)

---

## Why I Built This

Modern life creates constant administrative noise—bills, university circulars, hospital follow-ups, passport renewals, and travel tickets scattered across email threads, WhatsApp groups, and physical stacks of paper.

Most productivity tools treat life admin like generic task lists. **Life Admin Copilot** is designed specifically to answer one question:

> *"What do I actually need to deal with today?"*

---

## Key Features

- **Autonomous Document Extraction**: Scans circulars, invoices, and notices to extract exact due dates, payment amounts, and required documents with provenance verification.
- **1-Click Settlement**: Settle power bills, exam fees, and travel deposits directly via UPI with instant receipt generation.
- **Multi-Profile Vaults**: Keep personal obligations, elderly parents' healthcare, and freelance business filings completely separate.
- **Interactive Clutter Transformer**: Drag the live slider to watch physical paper clutter dissolve into calm digital stream cards.
- **Floating Action Dock & ⌘K Search**: Quick shortcuts for instant bill payment, live OCR scanning, admin access, and natural language command search.

---

## Tech Stack

- **Structure**: Semantic HTML5 with custom Web Component abstractions.
- **Styling**: Vanilla CSS3 design tokens, KokonutUI liquid glass cards, Magic UI conic border beams, and responsive layouts.
- **Typography**: Instrument Serif, Space Grotesk, and JetBrains Mono.
- **3D & Motion**: Three.js WebGL spatial console, GSAP ScrollTrigger timeline animations, Lenis smooth scrolling, and Vanilla-Tilt physics.
- **Audio Haptics**: Synthesized Web Audio API haptics (mechanical clicks, temporal clock ticks, sub-bass resonance).

## Getting Started Locally

No complex build pipeline required. Clone and launch with any standard local HTTP server:

```bash
git clone https://github.com/neurelith/life-admin-copilot.git
cd life-admin-copilot

# Launch local server
python -m http.server 3000
```

Open `http://localhost:3000/` in your browser.

- **Admin Password**: `admin` (or click "Auto-Fill & Log In" on the admin modal).
